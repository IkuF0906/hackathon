# 要件定義書

# システムの概要

本アプリは、ランダムにマッチした相手と時間制限つきのチャットができるチャットアプリである。

# 背景・課題

既存の朝活アプリは自分を律することを目的にしているため、挫折しやすいという問題がある。そこで、他者との繋がりを設けることで、朝活での挫折を防ぐチャットアプリを開発する。

# スコープ

何を作るか、何を作らないか

## 対象範囲

- ユーザー登録
- ログイン
- プロフィール・属性設定
- ランダムにマッチングを行いチャットルーム作成
- メッセージ送受信
- メッセージの検閲
- カード送受信
- カード作成・編集・削除
- もらったカードの一覧を表示

## 対象外

- 音声通話
- ビデオ通話
- ユーザーのメール認証
- メッセージの暗号化
- 管理者機能
- 負荷対応
- 多言語対応

# 非機能要件

動作の品質に関する要件

## 可用性

デモ動作時に機能が停止しない

## 性能

メッセージ送信後、1秒以内に画面に反映する

## 拡張性

将来的にマッチング履歴表示機能追加、カード編集の多様化などができる設計にする

## 運用・保守性

フロントエンドとバックエンドを分離する

## セキュリティ

最低限のセキュリティ（パスワードを平文で保存しないなど）を確保する

# 画面要件

どんな画面を作るか

## トップ画面

最初にアクセスすると表示されるページ。ログインボタン、ユーザー登録ボタンを表示する。

## ユーザー登録ページ

ユーザー登録を行うページ。メールアドレス、パスワード、属性などの入力欄を表示する。

## ログインページ

ユーザー登録済のユーザーがログインを行うページ。メールアドレスとパスワードの入力欄を表示する。

## ホーム画面

ログイン後に表示されるページ。マッチング開始ボタンを表示する

## マッチング中画面

マッチング中に表示されるページ。マッチングキャンセルボタンを表示する。

## チャット画面

チャット中に表示されるページ。メッセージ入力欄、今までのやり取りが表示される。

## カード送信画面

チャット終了後に表示される、カードの送信を行うページ。作成済みのカードが一覧表示され、送信するカードを選択できる。

## カード作成・編集・削除画面

カードの作成・編集・削除を行うページ。カードの新規作成、作成済みのカードの編集、作成済みのカードの削除ができる。

## もらったカードの一覧画面

チャット終了後にもらったカードの一覧を表示するページ。

## プロフィール画面

ユーザーのプロフィールの確認、編集を行うページ。
